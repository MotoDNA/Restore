# Re:Store · 가맹점 발주와 정산

가맹점이 **링크만 열어** 발주하고, 본사는 들어온 것을 한 화면에서 확정·출고합니다.
한 달이 지나면 그동안 쌓인 숫자가 **그대로 정산서**가 됩니다. 다시 입력하지 않습니다.

설치 없이 브라우저에서 씁니다. **Re:Call · Re:Bind 와 같은 회사 코드·아이디로 들어옵니다.**

**앱 — https://restore.dnalabs.kr/** (첫 고객: 구도로 통닭)

## 하는 일

### 가맹점 쪽 (계정 없음)
- **링크 + 핀 네 자리** — 앱을 깔지 않습니다. 카톡으로 받은 링크를 열고 숫자 네 자리만 넣습니다
- **품목을 눌러 담기** — 분류로 걸러 찾고, `+` 를 처음 누르면 최소 발주 수량까지 한 번에 올라갑니다
- **합계가 아래에 늘 떠 있습니다** — 면세와 과세를 갈라 세고 부가세까지 포함한 금액
- **내 발주 내역** — 접수 → 확정 → 출고 → 완료가 어디까지 왔는지, 송장번호까지.
  주문한 수량보다 적게 왔으면 그 줄이 빨갛게 뜹니다
- **본사가 확인하기 전(접수)까지는 스스로 취소** 할 수 있습니다

### 본사 쪽
- **발주 한 화면** — 손이 가야 하는 것(접수·확정)이 위로 옵니다. 점포·발주번호·품목으로 검색
- **확정 → 출고 → 완료** — 출고할 때 실제로 나간 수량을 줄마다 고칠 수 있습니다.
  모자라게 보냈으면 **그만큼만 청구**됩니다
- **가맹점 관리** — 점포마다 발주 링크와 핀. 문자 한 번으로 보냅니다. 핀은 언제든 새로
- **품목과 단가** — 관리자만 고칩니다. **면세/과세**를 품목마다 정합니다
  (생닭 같은 농축수산물은 면세, 포장재는 과세)
- **월정산** — 그 달에 나간 것을 점포별로 모아 **거래명세서 한 장**.
  **인쇄(PDF) · 엑셀(.xlsx)** 로 냅니다. 마감하면 그 건들은 잠깁니다
- **대신 넣기** — 전화로 받은 발주를 본사가 직접 넣습니다. 정산은 똑같이 잡힙니다

## 어디에 얹혀 있나

Re:Call(고객관리) · Re:Bind(제조공정)와 **같은 Supabase 프로젝트, 같은 계정**을 씁니다.
회사 격리·담당자 규칙도 그것을 그대로 씁니다. 계정을 따로 만들지 않습니다.

```
Re:Call   network-dna.html   고객 · 명함 · 미팅 타임라인
Re:Bind   bindery.html       프로젝트 · 공정 · 거래명세서
Re:Store  store.html         가맹점 · 발주 · 월정산
              └── 같은 데이터베이스 · 같은 로그인
```

어느 서비스를 산 회사인지는 `companies.apps` 로 가릅니다 (`{recall,rebind,restore}`).
안 산 서비스는 데이터베이스가 표를 통째로 닫습니다 — 화면이 가리는 것이 아닙니다.

## 만든 순서 — 고객에게 설명할 때

| | 무엇을 | 왜 그 순서인가 |
|---|---|---|
| **1. 그릇** | 표 4개와 접근 규칙 | 그릇 모양은 나중에 바꾸기가 가장 어렵습니다. 이미 쌓인 발주를 다 옮겨야 하니까요 |
| **2. 문지기** | 서버 함수 `store-gate` | 점주는 계정이 없습니다. 링크의 열쇠와 핀을 확인하고 그 점포 것만 다룹니다 |
| **3. 화면** | `store.html` | 넣는 쪽(점주)과 처리하는 쪽(본사)이 한 파일에 들어 있습니다 |
| **4. 종이** | 월정산서 | 다시 입력하지 않습니다. 쌓인 것이 그대로 종이가 됩니다 |

뒤로 갈수록 고치기 쉽습니다. Re:Bind 를 만들 때와 같은 순서입니다.

## 조심한 것

- **단가는 브라우저에서 받지 않습니다.** 점주 화면이 서버에 보내는 것은
  "무슨 품목 · 몇 개" 뿐이고, 값은 서버가 품목표에서 직접 꺼내 붙입니다.
  단가를 받아 쓰면 브라우저를 조작해 1원짜리 발주를 넣을 수 있습니다.
- **발주 줄에 품목명·규격·단가를 그때 값으로 박아 둡니다.** 품목표를 가리키기만 하면
  나중에 단가를 올렸을 때 지난달 발주서와 이미 끊어 준 정산서의 금액이 소리 없이 바뀝니다.
- **핀 네 자리를 둡니다.** 읽기만 하는 Re:Bind 링크와 달리 여기는 점주가 씁니다.
  링크는 카톡으로 돌아다니고, 점주는 폰을 바꾸고, 직원은 그만둡니다.
- **정산을 끊은 발주는 잠급니다.** 종이로 나간 숫자가 뒤에서 바뀌면 어긋납니다.
